# Rakaman suara

Muat naik fail ZIP daripada **Studio Rakaman** (`/studio/`) ke folder ini.
Anda boleh muat naik beberapa ZIP. ZIP yang lebih baharu menggantikan rakaman lama bagi ayat yang sama.

Kemudian jalankan `npm run voice:import` untuk menukar rakaman kepada pakej suara aplikasi (`audio/ms-MY/`).
